    Каким HTTP-кодом метод отвечает, если сумма отклонена?

    Кому
    архитектор
    Почему важно
    Пример ERROR сейчас приведён под кодом 200. Приложение, которое смотрит на код, покажет «сохранено», хотя операция отклонена, а тестировщик не знает, какой код ждать для неверной суммы.

    Отклонённая сумма получает 400 с message, код 200 означает только успешное сохранение.

  2. Q-02блокирует разработкуриск высокий · клиент

    По какой дате покупка относится к месяцу учёта: по дате совершения или по дате проведения?

    Кому
    владелец продукта
    Почему важно
    Сейчас Ф-2 и критерий приёмки требуют разного. Пока ответа нет, расходы попадут не в тот месяц, push придёт клиенту не вовремя, а приёмка не пройдёт при любой реализации.
    Риск
    Если счётчик ошибается на границе месяца, клиент получает неверный push, а исправить уже накопленные суммы после выпуска трудно.
    Варианты и последствия
    • По дате совершения покупки, время UTC+5 Ф-2 остаётся. Критерий приёмки №2 переписывается: сумма попадает в январский счётчик. Добавляется правило для push по событию, которое пришло после конца месяца.
    • По дате проведения покупки, время UTC+5 Ф-2 переписывается, критерий №2 остаётся. Поздних событий за прошлый месяц не бывает. Цель «в момент покупки» переформулируется под проведение.
    Если ответа не будет
    Команда реализует Ф-2 как написано: дата совершения, время UTC+5. Критерий №2 будет исправлен, push по событию за закончившийся месяц отправляться не будет.

    D-001, D-042, D-009, D-020, D-045
