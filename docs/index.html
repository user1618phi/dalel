Противоречие —
это сценарий с числами

Критерий приёмки относит покупку к месяцу проведения, а Ф-2 — к месяцу совершения

дано

Активная карта KZT, расходы за январь 10 000 ₸, за февраль 0 ₸.

когда

31 января в 23:58 по Алматы прошла авторизация покупки на 4 000 ₸. 1 февраля в 00:03 по Алматы покупка проведена (клиринг).

по Ф-2

Январь: 10 000 + 4 000 = 14 000 ₸, февраль остаётся 0 ₸

по критерию приёмки

Февраль: 0 + 4 000 = 4 000 ₸, январь остаётся 10 000 ₸

конфликт

Одна операция попадает в разные месяцы, поэтому расходы, а значит и момент достижения порога, получаются разными.

Сценарий — готовый тест-кейс.

вопрос автору · владелец продукта

Пропуск —
это вопрос с вариантами

По какой метке времени операция попадает в расходы и относится к месяцу в часовом поясе Алматы (UTC+5)?

ситуация

Покупку на 4 000 ₸ совершили 31 января в 23:58, а провели 1 февраля в 00:03 по Алматы. По Ф-2 она январская, по критерию приёмки — февральская.

вариант 1

По авторизации: расходы растут при авторизации, месяц — по дате авторизации

вариант 2

По проведению: расходы растут при проведении, месяц — по дате проведения

вариант 3

Учёт по событию проведения, месяц — по дате авторизации

рекомендация агента

Вариант 1. Цель «узнать о достижении личного бюджета в момент покупки» достижима только при учёте авторизации, а Ф-2 или критерий приёмки придётся исправлять при любом ответе.

Автор отвечает в файле, в терминале или в браузере; агент снимает замечания, задаёт уточнение и пересчитывает вердикт.

как устроено

Модель предлагает, код проверяет

загрузчик · нарезчик

PDF, DOCX, Markdown, HTML, текст. Битый файл даёт диагностику, а не аварию. Нарезка по структуре документа одинакова при каждом прогоне.

линтер

Правила без модели: формулировки, шаблон, единицы, таблицы API, пропуски финтеха, границы без приёмки. Работает без ключа и сети.

аналитик · ревизор · искатель пропусков

Модель проверяет каждый пункт, ищет противоречия и примеряет линзы предметной области. Данные карт перед этим маскируются.

вольный ревьюер

Свободный разбор без ограничений формата; каждое его замечание переносится в отчёт только с цитатой из документа.

оппонент · арбитр

Оппонент защищает автора и пытается опровергнуть замечание; спор решает арбитр по тексту документа.

интервьюер · тест-дизайнер

Коренные причины, вопросы с ситуацией и тестом, граничные значения и сценарии для тестировщика.
